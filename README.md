## Overview
This repository contains the solutions for **Lab #4a** covering DOM element selection, `addEventListener()` event handling, input validation with `if...else if...else`, safe text updates via `textContent`, and dynamic list generation using a `for` loop and `document.createElement()`.

## How to Run Each Question
1. Open the project folder (`bic21203-lab4a-javascript`) in **VS Code**.
2. Open `Q1/index.html`, `Q2/index.html`, or `Q3/index.html` in a modern desktop browser (or launch with **Live Server** in VS Code).
3. Test the interactive controls on each page:
   - **Q1:** Click **Change Message** to replace `"Welcome to my website!"` with `"Hello there!"`.
   - **Q2:** Enter test values (`5`, `10`, `15`, `10.5`, `abc`, and empty/whitespace input) and click **Check**.
   - **Q3:** Click **Generate** to display `"The number is 1"` through `"The number is 5"`, and click again to verify no duplicate items are added.
